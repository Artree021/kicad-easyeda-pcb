# 工具排错

以下是实际工作中出现过的条件与处理，不是所有版本必然存在的缺陷。先记录软件版本、最小触发条件和当前文件状态；修复工具前保护工程。迁移格式、层叠单位、原生铜和模型的细节见 [迁移与原生编辑](migration-and-native.md)。

## 先分清故障层次

顺序是：目标/焦点是否正确 → 工程与规则是否齐全 → 任务是否完成 → 输出是否覆盖目标 → 才判断设计是否有错。工具问题不要靠生成更多 PCB 候选解决。

### 返回成功，但结果为空或未保存

- **现象：** API 返回正常，重读没有对象；方法存在却恒定返回 `false`；批量关联后白屏，重开少了末批对象。
- **处理：** 查对应版本接口及返回值，在副本上按风险类别小试。写入、保存、重读、重载核对形成闭环后才扩批；每批保存并记录已持久化对象。
- **边界：** 不把失败返回忽略掉，也不把一次简单元件成功推广到多边形焊盘等其他类别。超时可能已经写入，先查当前状态再重试，避免重复对象。

### `pcbnew` 保存后网络归属变化

- **现象：** 悬空线段接触另一网络，保存/重读后其网络归属改变；程序内设置的网络名与落盘结果不同。
- **处理：** 写前检查端点、分支与附近异网铜，保存后逐对象比对网络。先在少量对象中验证，再执行已选定路径；出现改网时修几何连接并复核两侧网络。
- **边界：** 仅重新写回原网名不能消除实际短接；只比较对象数量也会漏过问题。

### 填铜后远处也变化

- **现象：** 候选板缺少匹配工程配置或规则，以默认间距重填，未修改区域也发生退铜。
- **处理：** 在加载前准备匹配的项目/规则/库上下文，记录其版本；恢复正确上下文后重新产生候选与检查，比较受影响区域。
- **边界：** 不把默认规则下的输出当原工程结果；文件恰好同名也不证明内容匹配。

### 零结果来自漏查、截断或错误分组

- **现象：** 计划分组名称替错，层号固定，报告达到条目上限；不同次检查数量大幅变化。
- **处理：** 明确对象/网络集合，记录层名到工具层号映射，核对总数、分页和输出上限。必要时分区枚举并去重；检查无匹配是目标确实不存在还是选择失败。
- **边界：** 输出更少不等于修得更多；扩大覆盖后的新增项也不等于本次修改引入的缺陷。

### 检查超时、进度不动或空面板

- **现象：** 严格检查等待超时，聚合进度被误认作当前填铜进度，重算面板暂时为空。
- **处理：** 先确认已有任务是否仍在运行或已经完成，取回同一次结果。确需逐层重建时，核实目标层和完成状态；正常重开前保存检查点并确认没有用户未保存编辑。
- **边界：** 不叠加多个长任务，不把超时算失败或空面板算通过。进程关闭超时先查是否自然退出，不立即强杀并重开多份。

### 同一几何在不同导出中看似全变

- **现象：** 归档文本与运行时导出逐字比较出现大量差异，或保存把一段线拆成数段。
- **处理：** 使用同一导出方式比较，再按对象语义展开差异。只在证明网络、层、线宽、端点、几何并集及相关属性相同后，允许比较程序做有限归一化。
- **边界：** 不忽略整个对象类别，不把所有缓存差异一概视为无害，不给未知单位套固定公差。详见迁移参考中的允许差异说明。

### 多轮廓或带孔铜区重载后丢形状

- **现象：** 内存中可见多个外轮廓，序列化或重读后只剩部分铜；把包围框或单个外环当作完整材料。
- **处理：** 用最小带孔/多外轮廓样本确认当前 API 的表示能力。历史成功替代是按一个外轮廓及其孔分别建立区域，重读、填充再对比实际铜。
- **边界：** 内存预览不是持久化验证；这种表示方法仍需在当前版本验证，不能删除未知孔洞以求显示完整。

### 连通分析误报孤岛

- **现象：** 自写解析只读取填充多边形，漏掉带线宽热焊盘辐条、孔桶或实际跨层连接。
- **处理：** 对照真实输出验证解析覆盖，建立包含焊盘、走线、填铜、辐条和允许层对过孔的材料连接图。钻孔/槽会减去铜，但金属化孔桶的连接作用也要计入。
- **边界：** 被标记的一个焊盘与过孔重合，不证明整个分组接回主网；不同层过滤目的必须在建图前确定。

### GUI、调试目标或窗口失联

- **现象：** 桥接显示已连接但读不到目标，最小化后 UIAutomation 没有网页节点或画面停止刷新。
- **处理：** 动态枚举并验证应用、目标页和活动文档；先查窗口是否最小化、对话框是否在退出、任务是否还在运行。允许非激活恢复时，仅恢复已核实的目标窗口并确认前台未变。
- **边界：** 端口、窗口句柄、坐标和第一个页面都不是固定入口。需要桌面键鼠时事先约定使用时段；目标或焦点不符先停，不盲点。不得从浏览器配置中提取登录凭据来补工具能力。

### 中文变问号、选择器匹配不到

- **现象：** shell 管道、子进程或富文本剪贴板编码改变中文；精确匹配无结果但页面仍正常。
- **处理：** 优先结构化参数或明确 UTF-8 文件，检查真正传入和回读的字符串。界面写入先用小段验证；剪贴板操作保存并恢复原内容，逐段截图检查显示与保存。
- **边界：** HTML 剪贴板的编码读回异常与页面实际乱码分开判断；不凭一次无匹配断言界面或文档已变化。

### Python 环境或历史脚本不兼容

- **现象：** 普通 Python 无法载入 `pcbnew`，几何扩展 ABI 冲突，旧脚本使用固定项目 ID、工作目录或导入即执行写操作。
- **处理：** 发现当前已安装且兼容的解释器与库；必要时将 EDA 读写与一般几何分析分进程，用明确格式交换数据。复用前检查脚本参数、顶层代码、默认输出和副作用。
- **边界：** 不硬编码其他人的软件目录，不为一次读取安装整套环境；不能将 `import` 当成无副作用读取。

### 权限/策略阻断

- **现象：** 自动执行桥、应用启动或临时文件清理被策略明确拒绝。
- **处理：** 标明被拒的动作和现有证据；在许可范围内改用只读导出、用户提供画面或已有接口，必要时由用户处理受限步骤。
- **边界：** 不换 shell、编码或其他入口重复同一受限操作。临时文件未删、清理未完成应如实记录，不报告已成功。

## 复现记录最小项

软件/接口版本、源快照、最小对象与操作、预期/实际结果、错误原文、已验证处理、仍未证明的部分。保存在项目的工具记录中；提炼到公开技能前移除路径、账号、文档 ID、固定坐标和工程数据。
