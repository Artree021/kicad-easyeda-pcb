# 设计、人工布线与审查

## 器件与原理图

1. 将功能拆为供电/保护、模拟链路、转换/时序、处理器/时钟/调试、通信及连接器；建立有来源的型号、封装、引脚和网络映射。选择常见可购买封装，核查完整料号后缀及厂家封装图，而非只看系列名或库名。
2. 外置 ADC 选型要核对总转换率、通道切换建立时间、源阻抗、输入范围、供电时序、基准及数字接口电压。每通道采样率、扫描内时差、传感器物理带宽和 CAN 报送率分开计算。12 位分辨率不等于力测量精度。
3. 供电检查工作与故障情况：功耗/温升、LDO 稳定电容的有效容量与 ESR、关断/未上电注入、保护器件钳位电压及电流路径。普通 ESD 元件的存在不能证明任意误接、浪涌或 EMC 合格。
4. 检查 MCU 的具体封装引脚、启动配置、时钟与负载电容、复位、烧录口和未用引脚处理。核验相似型号的实际引脚：例如 TLVH431 与 TL431 的 DBZ 引脚不能直接照搬。
5. 分页按信号流组织，标题/位号/参数/网络名不相互重叠。符号与焊盘一一对应；需要接地的连接器固定脚也应在原理图中表示。页面大小按实际内容调整，避免无意义大图框或拥挤文字。
6. 显示连接线的视觉修复后重新导出网表，比较 `(位号, 引脚号) -> 网络`，包括电源和连接器固定脚。相同网名与相同网络数量不保证引脚连接相同。

项目脚本若采用确定性 UUID 和声明式清单，可帮助保持图元身份；构建原理图与重建 PCB 应分开，避免整理文本时覆盖人工布局。

## 布局与层规划

- 先确定板框和接插件本体/配对插头的空间。连接器卧贴/立贴、底面镜像、开口朝向及焊脚伸出都要按变换后的坐标检查，不能仅凭旋转角数值。
- 用实际封装焊盘、本体和装配空间检查重叠；2D 3D 与 courtyard 各有用途。上下两面可以对置，但考虑回流、遮挡、维修和插拔。
- 围绕端点同时规划走线：高阻模拟输入与反馈环、ADC 输入 RC 与去耦、晶体环路、CAN/保护优先。元件在逻辑上邻近不等于引脚出口合适。
- 选择适合当前密度和回流的层叠。不要为了“用上内层”切碎地，也不要在外层拥挤时拒绝经过规划的内层跨接。检查信号换层前后的参考面和邻近回流过孔。
- 某紧凑传感器板选择 F / GND / bridge / bridge / GND / B 六层；这是针对该布局的结果，新板可选择不同合理层数。
- 以边沿速率、驱动阻抗、长度和回路面积判断敏感程度，不能仅因采样为 1 kHz 就忽略 SPI 或时钟边沿。

## 人工选线与记录

每条路径的记录至少含：

| 字段 | 用途 |
| --- | --- |
| 网络、起终引脚、经过的分支/元件 | 防止只查主干漏掉支路 |
| 层序、线宽、实际关键坐标/对象 ID | 能在实际板上找到该路径 |
| 换层点、参考面、回流观察 | 检查完整信号回路 |
| 电气目的与局部观察 | 说明为什么该摆放和路径合理 |
| 来源板哈希、状态、证据图 | 防止旧审查冒充当前通过 |

允许脚本把明确选定的点转为原生直线/圆弧，但初始记录状态保持待审查。先检查实际铜和邻居，再写结论；不能模板化批量填“已通过”。修改一条路径后复查它、相邻受影响路径、铜区及参考面。

CANH/CANL 配对检查主路长度、差值、层转换和局部对称；TVS 与终端支路另计长度。不要为了绝对等长加入多余蛇形。几何等长不代表精确阻抗、波形或 EMC 已验证。PCB 上仅几毫米的路径也不能省略针号及极性检查。

## 圆弧、铜区与收尾

- 使用原生铜圆弧和相切接点；不仅检查端点，还检查线段中部相交、T 分支、倒退和重复铜。
- 计算每个局部圆弧的内半径 `r - w/2`。`r = 0.10 mm、w = 0.20 mm` 的中心线很圆，内缘仍可趋于尖角。识别候选后看实际铜的并集，不能把全部小圆弧一概判为问题。
- 焊盘、过孔、泪滴覆盖的角需看整片铜边；仅用点命中测试会漏掉露出的尖角。真正重叠的边界与虚拟中心线分叉区分处理。
- 小范围同网络异形铜可替代拥挤的多根平行供电/GND 线，但先确认电流路径、间距、焊接热连接与回流。不能用铜块掩盖短路或未经分析的模拟节点耦合。
- 地铜是否“消失”先检查显示状态、区域定义和实际填充三者。重铺铜后检查孤岛、窄颈、焊盘/过孔连接及参考面空洞。
- 布局/路径稳定后再加适当泪滴、板框圆角和简洁接口丝印。收尾也可能改变铜/阻焊，需重新审查。丝印要符合实际生产字高/笔宽并避开露铜和本体。

验证顺序：实际 ERC 与 PCB DRC/未连接/原理图一致性 → 每网/电气与装配检查 → 制造输出独立检查。它们互相补充；没有一个可以单独宣称功能或生产完全正确。
