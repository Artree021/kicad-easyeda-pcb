# 需求、原理图与布局

在新板设计、接手已有原理图或大幅改布局时读取。先填写 [设计约定](../templates/design-contract.md)；规则的目标值及跨软件对应方式见 [规则与来源](rules-and-sources.md)。只展开当前项目实际存在的功能，不默认增加接口、保护器件或层数。

## 按阶段推进

需求明确后改原理图，原理图核对后做布局，布局验收后进入正式布线。每阶段给出当前版本、实际检查和未解决项。用户要求看图确认的节点应等待确认；已经授权连续完成的工作不重复请示。布线遇到布局问题可以回到局部摆位，但要记录影响并重新检查，不能把阶段顺序理解为器件一旦放下就不可移动。

| 阶段 | 形成的结果 | 转入下一阶段前检查 |
| --- | --- | --- |
| 需求 | 功能、供电、接口、机械、工艺、预算和改动边界 | 关键条件有来源；未知量有假设及影响；谁确认哪些节点已约定 |
| 原理图 | 可读的电路、精确料号与封装/针号映射 | 电源和接口逐脚核对、实际 ERC、关键状态分析；改原方案的原因可解释 |
| 布局 | 实际封装摆位、层规划、关键走线通道 | 两面装配、插拔、高度、大电流往返通路、关键引脚扇出可行；提供全板及关键区域图 |
| 布线 | 逐网选定的原生铜路径 | 完整路径、分支、内外铜边、填铜、回流和受影响邻网通过约定检查 |

## 先理解需求和原方案

- 从已有工程建立权威版本；用户提供的原理图和封装是输入，不把整个项目描述为 AI 从零设计。先保留已确认功能、接口针序、数量、尺寸和人工修改。
- 明确板框、安装孔、PCB 板厚以及装配后的最高点。板厚与元件高度是不同约束；同时考虑底面器件、插头本体、线束弯曲和外壳。
- 对每条电源记录正常/极限输入、连续/峰值负载、启动、纹波、允许温升与返回路径。对每个接口记录方向、上下游、电源域、配对件、针序、线长、终端和故障后动作。
- 低高度电容阵列、特定接插件或 IMU 结构可能承载用户未明说的设计意图。先解释“为何要换、得到什么、代价是什么”，不要把可优化项默认变成必须整改。
- 已有并联小电容不能只因零散就换成高罐电容；替代需比较有效容量、偏压、ESR、纹波能力、稳定性、回路和高度。相同标称容量不表示可直接互换。

## 原理图：电气和可读性一起核对

按供电/保护、处理器/时钟/调试、模拟/采样、通信和连接器组织页面。让信号流、局部连线、网标、标题、位号和参数容易跟踪；页面大小按实际内容选择。整理表达后比较逐引脚网络，不用“网名数量没变”证明连接没变。

重复通道保持共同方向和相近排列，电源页沿入口、变换、输出及控制展开。图中保留必要的计算依据和布局意图，在全图与实际阅读尺度检查；参考案例的图纸尺寸、颜色和器件数量不自动成为新板约束。

原理图阶段就检查具体封装与针号。完整料号后缀、厂商封装图、符号引脚、实际焊盘号和固定脚一起核实；外观相似或库名相同不能代替核对。只整理文本时，不能顺便重建并覆盖已有 PCB 布局。

按实际电路选用以下检查：

| 对象 | 关键检查 |
| --- | --- |
| MCU | 精确封装的电源/地、内部稳压电容、复位/启动、时钟、调试口；复用、定时器、DMA 与固件约束；未用脚及固定脚处理 |
| 电源 | 稳态、启动和负载阶跃；功耗/结温；输入输出有效电容与稳定性；保护的电压、电流、能量和时间边界 |
| 多电源域 | 主输入、外设、USB、调试器等实际组合；先上/后下、带电信号、I/O 注入、稳压器反向电流和接口断电行为 |
| 采样链路 | 量程、共模、源阻抗、RC 和采样建立、基准、漏电；区分传感器带宽、ADC 转换率、逐通道扫描时差、数据报送率与最终精度 |
| 时钟 | 晶体 ESR、负载/寄生、电容、驱动和启动条件；不能从低采样率推断数字边沿不敏感 |
| I²C / SPI | 全系统上拉与电容、逻辑域和地址；SPI 时序、CS 默认态、未选中 MISO、高阻及供电顺序 |
| 执行器输出 | 无电、上电、复位、调试暂停、棕断、通信丢失和恢复时的真实电平/高阻态；考虑固件卡死但 PWM 继续、驱动锁存等情形 |

风险分析按系统责任和实际使用场景展开。ESD 元件、保险丝或看门狗的存在不自动证明所有误接、持续再生能量或失效状态可接受。没有需求的故障测试不擅自执行。

## 布局：先留回路和通道

密集板先形成空间、关键回路、走线通道三类视图，可以在同一张草图中表达。包括固定件、敏感区、大电流供电及回流、主要信号出口、层转换、测试与维修位置。评估通道是否可走时，用真实引脚与铜空间，不能只看模块方框整齐。

1. **机械锚点和接口。** 按配对件确认卧贴/立贴、插入口、锁扣、焊脚及底面镜像。卧贴且要求从板边接线时，插口朝板外并留出实际插拔空间。屏幕上的旋转角不等于正确方向。
2. **电源群组和主通道。** 将稳压器及相关电容、电感等按实际拓扑成组摆放，缩小脉动电流回路；让反馈取样正确且远离开关噪声。先保留主要负载的供电和返回通道，避免事后在缝隙中拼细铜。
3. **MCU、去耦和时钟。** 试走关键引脚出口。去耦看电源脚→电容→地的完整路径；晶体看 MCU 脚、负载和返回回路。封装中心距离近不等于连接良好。
4. **模拟、传感和通信。** 高阻输入、基准与 ADC 沿信号流摆放，避开开关区；接口保护靠入口且泄放路径直接。保护器件的容量、支路和回流也要考虑。CAN 的保护布局可参考对应收发器手册，不能照抄示例的全部元件值。[TI TCAN1042-Q1 布局章节](https://www.ti.com/lit/ds/symlink/tcan1042-q1.pdf)
5. **其余元件和测试空间。** 考虑电源/运行指示、编程、探针与附近地、外壳装配后可达性；小焊盘可见不代表容易测量。底面器件还要检查散热、插拔和维修遮挡。

布局退出前试走几条最受约束的线路：主电源、拥挤扇出和关键接口。若普遍出现长绕行、过孔拥堵、地参考被切断或为一条线反复挪多处，先重看群组位置及朝向；不要把布局失败推迟成布线收尾问题。

## 间距不能只设一个数

数值及工艺来源写入项目规则表，至少区分：

| 类别 | 需检查的实际对象 |
| --- | --- |
| 铜电气间隙 | 异网铜、板边、孔壁、线宽、连接颈和工艺公差 |
| 不同器件的焊盘关系 | 同网及异网焊盘铜；穿孔/过孔与贴装焊盘；铜相交、孔相交与仅间距偏小分开 |
| 焊接空间 | 阻焊桥、锡膏开窗、吸锡路径、热对称、焊接和返修方式 |
| 本体及装配空间 | 最大本体/引脚、庭院、配对插头、锁扣、线束和工具空间 |
| 高度和机械 | 两面元件、外壳、安装受力、开槽和局部禁布区 |

同网不等于可重叠装配。对不同器件，枚举变换后的真实焊盘、钻孔和开窗；自定义焊盘的外接矩形不是实心铜。缺庭院或通用 3D 模型无碰撞时仍需实物尺寸核对。保留用户要求的默认焊盘，优先整体移动/旋转器件和调整局部走线，不裁剪焊盘来隐藏冲突。

孔检查要双向覆盖：新建/移动孔对所有受影响贴装焊盘；新建/移动贴装焊盘对所有既有孔，并覆盖孔贯穿的正反两面。普通小贴片优先焊盘外引孔；确需盘中孔时，明确工艺、开窗及成本，普通盖油不能直接当成填孔盖铜的等价方案。

## IMU 等机械敏感器件

记录实际传感轴、针一、板面和机体坐标关系，分别核对镜像与旋转；安装后按已知姿态验证。热点、紧固应力、开关电感和振动源的影响需要结合具体型号。厂商可能对本体下布线、邻近电容和多 IMU 布置提出专门要求，只适用于其明确覆盖的器件。[Bosch IMU 安装说明](https://www.bosch-sensortec.com/media/boschsensortec/downloads/handling_soldering_mounting_instructions/bst-mis-hs000.pdf)

挖槽、浮岛、软连接和加热仅在项目确实要求时采用，检查支撑/共振、热应力、跨槽走线与返回路径、加工和安装强度。不要把“有槽”当成隔振通过，也不因历史板采用浮岛就给所有新板加槽。加热电阻按实际功耗、温度降额及热分布选封装。

## 丝印与布局交付

密集板优先标接口功能、针一、极性、电源/地、调试、按键和方向；普通小件位号可按用户偏好隐藏，但位号文字和默认封装本体图形是不同对象，不能一并删除。标识避开实际开窗、器件遮挡、板边和孔，保留有用的极性记号。局部冲突逐项处理，不用整类隐藏取得“零警告”。

布局交付图应能看清接口朝向、两面元件、关键电源通道、敏感区和剩余拥挤处。记录哪些位置固定、哪些可在布线时小调，以及调整后必须复核的条件。下一阶段使用 [布线与实际铜检查](routing-and-copper.md)。
