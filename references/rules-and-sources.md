# 规则与来源

## 开工先建规则表

使用[规则模板](../templates/rule-profile.md)记录本次厂商、制造及贴装服务、层数/铜厚/板厚/工艺、资料日期、KiCad与嘉立创版本。制造极限、设计目标和用户偏好分列；未确认的数值留空，不能把历史板的参数当默认值。

1. 选定实际要下单的服务和工艺，核实其最新能力。国内与海外服务、普通与高级工艺、不同铜厚的规则可能不同；官方能力页是入口，不代替本次订单确认。
2. 把相关要求分别映射到KiCad全局约束、网络类、自定义规则、封装庭院/实体检查，以及嘉立创对应规则。无法原生表达的内容安排额外几何检查或人工审图。
3. 核对生效对象、单位、网络类分配、优先关系、严重程度及排除项。保存工程规则文件；只保存PCB几何而漏掉项目配置或自定义规则，会丢失检查条件。
4. 在独立小样本或工程副本中设置一个代表性违规，确认检查能报出来；用规则解析/约束查询确认实际命中。不为验证而改正式版，不用大批量试错代替这一小步。
5. 布局前确认元件间距与高度，布线前确认线宽、孔、差分和圆角，迁移前比较双方规则。变更规则后重查受影响范围，发布前对当前完整工程验收。

KiCad的制造最低约束、网络类和自定义规则承担不同作用，违规还可以被配置为错误、警告或忽略。因此“零错误”必须同时说明启用的检查、排除项和警告。[KiCad规则与DRC手册](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)

## 不要混为一项的距离

| 对象 | 要明确的条件 | 常见遗漏 |
| --- | --- | --- |
| 不同网络铜 | 铜边到铜边，不是中心距 | 线宽、过孔盘、泪滴、填铜扩展 |
| 同网焊盘及器件 | 焊盘、器件实体、焊接与可装配性 | 同网重叠可能不触发短路检查 |
| 孔与铜 | 钻孔/槽实际形状、环宽、孔铜与孔孔距离 | 只画圆心；在另一面切断电源通道 |
| 板边/开槽 | 铜、器件实体和机械加工边界 | 圆角槽端、连接器本体、IMU桥接区 |
| 贴装与接线 | 庭院、工具、线束和插拔方向 | 卧贴接口朝板内；3D外观代替尺寸核对 |
| 阻焊/锡膏/丝印 | 实际开窗、桥宽、字符可读与焊盘距离 | 库属性正确但导出形状或缩放改变 |
| 高度 | 裸板、上下侧器件、连接器及线束包络 | 只规定板厚，没管装配后总高 |

元件数据手册的封装尺寸、PCB推荐焊盘与装配服务的元件间距并不是同一个值。不要用一个全局clearance覆盖全部条件。

## 对齐两软件的检查口径

发现差异时保留同版源文件，挑一个能定位的违规解释其两端对象、层、测量值、阈值和规则来源，再分类：

- **源设计问题**：已有碰撞、断路、过窄或缺少装配空间。
- **规则问题**：目标更严格，源规则未启用、被覆盖或被排除；庭院缺失等也影响覆盖。
- **转换问题**：网络、圆弧、封装变换、层或开窗的含义改变。
- **目标状态问题**：未保存、旧缓存、重填后铜形改变、库关联触发更新。
- **检查口径问题**：显示上限、只报第一处、范围选择或忽略项不同。

据此修正具体原因。不要只比报错数量，也不要通过降低标准让两个数字相等。没有完成源/目标对照时写“原因尚未证实”。
