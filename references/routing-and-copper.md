# 逐网布线与实际铜检查

在路径规划、脚本生成线段、圆角修复、填铜或回流审查时读取。记录使用 [逐网审查模板](../templates/route-review.md)。线宽、间距、主载流层和弯角策略来自当前项目约定，不从历史板复制数值。

## 控制 KiCad 的方式

默认由 AI 按网络决定端点、整体走向、支路、层、线宽和换层位置，再通过交互编辑或脚本生成原生线段、圆弧与过孔。脚本负责执行已选定的几何；其成功返回不证明选路合理。

KiCad 的交互式布线器可按所配置的规则进行推挤、绕障和差分布线，不应把它描述成软件内置的全板自动布线器。[KiCad PCB Editor 手册](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)

本工作流默认不调用外部全板自动寻路，也不把批量寻路后再检查称为逐网规划。用户若明确选择其他布线模式，按该次约定执行并准确记录工具。交互推挤也可能影响邻线，需确认最终几何，而不是把“手动”当作免检理由。

每条路径先看完整走廊，再落线：

1. 定位真实起终焊盘和所有分支，确认其网名、用途和当前约束。
2. 检查引脚出口、可用层、返回参考、大电流与敏感邻居，选定主要走向。
3. 选择必要的换层、分支和弯角，预估能否在规则内连接。明显难走时回看布局，比较旋转、移动、合法引脚重映射和换层；不能为“少过孔”牺牲回流或装配。
4. 执行小批次几何，保存后回读，检查真实连接和网络归属。
5. 检查整条连通路径及支路、实际铜边、受影响邻网和另一面，再标记该网的检查状态。

在约束都满足时优先简单、直接的连接，减少无用折返和过孔。局部短并不一定使整个回路更好；跨过开关区、切断参考地或堵塞主电源通道时应重新规划。

## 为什么拼线会留下直角

分段写入容易只修一段的两端，漏掉下一段方向、线段中部接点、T 分支、焊盘/过孔覆盖边和多个铜区合并处。后续圆弧只改中心线时，真实内铜缘还可能是尖角；已圆角的区域相互叠加，也可能形成新的内直角。

把圆弧作为当前约定时，布线阶段就完成内外铜边处理，不留给迁移后统一补救。不能把这一偏好解释成“所有直角必然导致电路失效”；项目明确要求修复时，仍须按约定完成，不能以 DRC 为零免除。

检查包含：

- **原生路径：** 直线与圆弧接点连续、相切，无倒退、重复段、极短搭接和未解释的分叉。
- **弯角内缘：** 对恒宽圆弧，内半径为 `中心线半径 − 线宽/2`；内半径接近零时，中心线看起来圆不等于内缘足够圆滑。半径来自项目几何及工艺约束，不用单一数值覆盖全板。
- **实际铜并集：** 查看弧线、宽线、焊盘、过孔、铜区和泪滴合并后的外轮廓与内凹角。中心点落在焊盘内不能豁免露出的尖角，也不能把封装本身的规定轮廓擅自磨圆。
- **短边覆盖：** 扫描器须记录离散精度、最短边/角度阈值、过滤与未覆盖区。只查长边得出的零结果不能写成全部铜边通过；用原生几何和局部图区分真实尖凹口与圆弧离散误差。
- **改动后：** 重查邻网间距、连接颈、填铜、孔及返回路径。仅修人工定位的角，避免大范围几何重构把远端已正确铜边改坏。

## 铜区、回流和载流

铜区定义、屏幕显示与实际填充是三种状态。区域存在或显示大块铜，不证明它接入目标网络；重填后逐层检查孤岛、窄颈、热连接、过孔和焊盘的实际连接。

电源从入口经保护和负载再返回，沿完整往返路径检查焊盘出口、铜颈、辐条、过孔阵列、连接器和层间连接。大铜面积不能代替载流、压降或温升判断。热焊盘与实心连接按电流、散热和焊接选择；如果项目偏好实心直连，应落实到实际区域/焊盘设置并核对重填结果，不能牺牲小件热对称或返修条件。

新增回流孔会在其它层产生孔洞和间隙。改善一面地回流时，要同时查看所有受影响电源层与相邻信号参考，防止补好背面却切窄正面电源。通孔穿过哪些层，就检查哪些层；层名以当前工具实际映射为准。

如果项目规定外层承担主要供电和回流，应单独构建仅允许外层与实际跨层导体参与的连通检查，逐一核对源和负载。全层连通不能证明指定层通道有效；也不能先让搜索穿过内层，再过滤结果来冒充外层检查。

对重要信号，沿全路检查真实参考面与换层返回路径，避免切地、槽缝和过孔反焊盘形成的断口。存在相邻地层或一颗接地孔不等于返回路径已经闭合。高速和敏感结构的参考与差分要求，按器件/接口和实际叠层判断。[TI 高速布局指南](https://www.ti.com/lit/an/slla414/slla414.pdf)

## 差分与时序

差分对先按器件、协议、边沿、拓扑和实际板厂叠层定义阻抗与允许时延差，明确测量端点；不能用“等长”代替阻抗或波形验证。主路与终端/保护支路分别统计，不把整网铜总长当成端点间路径长度。不同层、过孔、连接器和封装的传播条件也需考虑。

CANH/CANL 成对规划，保持走向、参考和必要换层尽量对称；TX/RX 是收发器逻辑侧信号，不属于 CANH/CANL 差分对。匹配目标按具体器件、速率和长度制定，不自行追求零长度差而堆蛇形。用户明确坚持零差时，解释补偿代价、定义端点和计量精度，再按该约束验证可行性；约束冲突交用户决定，不能静默放宽目标。总线端接按系统物理端点设置，检查支线和环路传播预算，不能让每个节点默认带终端。[TI CAN 物理层说明](https://www.ti.com/lit/an/slla270/slla270.pdf)是经典 CAN 历史资料，不能据此给 CAN FD/XL 套用统一速率或距离上限。

需要补偿时先减少不对称，在差异附近有限补偿，并检查蛇形耦合和连续参考面。SPI 等单端信号按具体时序及负载安排，普通 GPIO/PWM 不默认相互等长。实际协议互通、波形、EMC 和受控阻抗生产验收另行验证。

## 几何和工具结果要能自证

以下条目来自既往工具复现，是应在当前版本验证的防错方法，不是软件永久行为声明。

| 问题 | 防错方式 |
| --- | --- |
| 复制 PCB 后填铜规则变成默认值 | 在加载和重填之前准备同名工程配置、引用的规则文件与必要库；回读并断言真正使用的规则。填完才复制配置不能补救先前错误上下文。 |
| 分组检查漏掉真实端点锚定 | 保留计划网络与稳定对象对应，保存重载后比较每段线、弧、孔和区域的网名；悬空铜接触其它网络时曾发生网名传播，零 DRC 不能代替此检查。 |
| 硬编码层号漏查真实铜层 | 用当前工具的层名/命名常量建立映射，报告保存层名、层对和覆盖范围；不同版本不能沿用旧整数表。 |
| 孔洞被当实心铜或只用外接矩形 | 使用实际焊盘/铜区多边形及孔形状；构建多区多孔最小试件，核验铜内点、孔内点和面积。确认 API 参数和实际孔洞表示，不能仅改调用就沿用旧报告。 |
| 并联铜片总宽被当成连续载流宽度 | 同时报告最大连续片、总截面、各片两端连接和旁路。各分支不必均流，单个截面数字不直接等于载流能力。 |
| 裁切窗口漏掉真正通路或瓶颈 | 检查裁切边界交点、完整源到负载路径及窗口外旁路；自定义焊盘外接框不作为材料。 |
| 元件移动后漏查旧孔侵入 | 同时检查“移动孔对原焊盘”和“移动焊盘对原孔”，覆盖相关板面与开窗。 |
| 交换引脚后旧生成器恢复错误网络 | 将已采用的脚网映射同步到声明式来源；只在隔离副本验证受影响生成步骤和有限合并结果，保留真实端点断言，不直接重跑整板覆盖人工成果。 |

计算平面净铜时扣除实际孔/槽；孔桶镀铜、插针和焊锡是不同导体，另作连接和载流分析。穿过孔中心的单个二维窄截面也不能自动认定整条路径的串联瓶颈。几何简化、公差和浮点归一化须有当前证据，不能通过放宽到“差不多”获得相等。

## 检查和收尾

每次改动先检查本次及其影响范围，遇到新增错误或阶段验收要求时扩大。路径稳定后再处理适当泪滴、标识和输出；填铜与泪滴会改变实际铜，不能以之前检查代替最后状态。

最终需要当前工程对应的 ERC、PCB DRC/未连接、逐脚网表一致性、逐网与实际铜/装配审查，以及制造输出检查。检查报告应记录配置、忽略项、截断/输出上限、源版本及完成状态。未执行的写“待验证”，接受保留的按用户决定记录，不能用无限微调替代明确收尾。
